四种鸡尾酒模板。

几乎每一杯鸡尾酒都是这四种模板之一的变体 · dissolvedsolids.co

1. 酸款 (Sour)

烈酒 + 柑橘 + 甜（3:1:1，可选加蛋白）

最灵活的模板。酒感清晰、均衡、解渴。加冰强力摇制，双重过滤。

  • 威士忌酸 (Whiskey Sour)：波本 + 柠檬 + 糖（+ 蛋白）
  • 黛吉利 (Daiquiri)：朗姆酒 + 青柠 + 糖
  • 玛格丽特 (Margarita)：龙舌兰 + 青柠 + 君度（君度 = 甜）
  • 琴蕾 (Gimlet)：金酒 + 青柠 + 糖／青柠果露
  • 蜂之膝 (Bee's Knees)：金酒 + 柠檬 + 蜂蜜
  • 边车 (Sidecar)：干邑 + 柠檬 + 君度
  • 皮斯科酸 (Pisco Sour)：皮斯科 + 青柠 + 糖 + 蛋白
  • Junos Sour：⭐ 日威 + 柚子 + 蜂蜜 + 蛋白
  • Kopi 酸 (Kopi Sour)：⭐ 威士忌 + Kopi-O + 椰糖 + 柠檬 + 蛋白

拇指法则：想甜一点就加甜；想锐利一点就加柑橘；想烈一点就加烈酒。

2. 萨泽拉克 / 古典 (Sazerac / Old Fashioned)

烈酒 + 糖 + 苦精（60 毫升 / 1 茶匙 / 3 滴，大冰搅拌）

最古老的鸡尾酒模板。酒感清晰、搅拌、无柑橘。展现基酒本身。

  • 古典鸡尾酒 (Old Fashioned)：波本 + 糖 + Angostura
  • 萨泽拉克 (Sazerac)：黑麦 + 糖 + Peychaud's + 苦艾洗杯
  • 曼哈顿 (Manhattan)：黑麦 + 甜苦艾酒（苦艾 = 糖）+ 苦精
  • 内格罗尼 (Negroni)：金酒 + 金巴利 + 甜苦艾酒（金巴利 = 苦的一侧）
  • 林荫大道 (Boulevardier)：波本 + 金巴利 + 甜苦艾酒
  • Martinez：金酒 + 樱桃利口酒 + 甜苦艾酒 + 苦精
  • 椰糖古典 (Gula Melaka OF)：⭐ 波本 + 椰糖 + 苦精
  • 梅斯卡尔内格罗尼 (Mezcal Negroni)：梅斯卡尔 + 金巴利 + 甜苦艾酒

拇指法则：任何干净的烈酒都能换基底。糖可以是糖浆、土糖、蜂蜜、龙舌兰糖、椰糖。苦精决定个性。

3. 气泡 (Spritz)

苦味利口酒 + 葡萄酒 + 苏打（3:2:1 冰上，加装饰）

低酒精、解渴、量大。为下午慢喝而设计。

  • 艾普罗气泡 (Aperol Spritz)：艾普罗 + 普罗赛克 + 苏打
  • 金巴利气泡 (Campari Spritz)：金巴利 + 普罗赛克 + 苏打
  • Hugo Spritz：接骨木花 + 普罗赛克 + 苏打 + 薄荷
  • 错版内格罗尼 (Negroni Sbagliato)：金巴利 + 甜苦艾酒 + 普罗赛克（不加苏打）
  • 美国佬 (Americano)：金巴利 + 甜苦艾酒 + 苏打（不加葡萄酒）
  • 洛神气泡 (Roselle Spritz)：⭐ 洛神糖浆 + 金酒 + 青柠 + 卡瓦
  • 柠檬利口酒气泡 (Limoncello Spritz)：柠檬利口酒 + 普罗赛克 + 苏打

拇指法则：苦味利口酒决定颜色与苦感，葡萄酒决定节庆感，苏打决定饮量。三者都可以换。

4. 高球 (Highball)

烈酒 + 长调辅料（1:3 大量冰上）

最简单的鸡尾酒模板。冰上加烈酒和辅料，有时挤点柑橘。

  • 金汤力 (Gin and Tonic)：金酒 + 通宁水
  • 威士忌高球 (Whisky Highball)：威士忌 + 苏打
  • 莫斯科骡子 (Moscow Mule)：伏特加 + 青柠 + 姜汁啤酒
  • Dark and Stormy：深色朗姆酒 + 青柠 + 姜汁啤酒
  • Paloma：龙舌兰 + 葡萄柚 + 青柠 + 苏打
  • 自由古巴 (Cuba Libre)：朗姆酒 + 青柠 + 可乐
  • 小金桔高球 (Calamansi Highball)：⭐ 伏特加／金酒 + 小金桔 + 苏打
  • 班兰柯林斯 (Pandan Collins)：⭐ 金酒 + 班兰 + 青柠 + 苏打（酸款 + 高球混血）

拇指法则：冰的质量比烈酒还重要。大颗干净的冰块，装满杯，倒烈酒，加冷的辅料。轻轻搅一下。
