隐私政策，简短说。

一份简短、坦诚的说明：dissolvedsolids.co 会收集什么、不会收集什么，以及对于经过我们手里的资料，我们会怎么处理。

最后更新：2026 年 5 月 16 日

本网站收集什么

不会自动收集任何东西。dissolvedsolids.co 是托管在 GitHub Pages 上的静态网站。我们不使用 Cookie、追踪器，也没有任何分析脚本。我们不会对你的浏览器做指纹识别。你打开网站时，我们不知道你是谁，也不会去查。

你的浏览器在加载页面时，会把标准的 HTTP 请求标头（IP 地址、用户代理、来源页面）发送给 GitHub 的服务器。网络本来就是这样运作的。GitHub 可能会按照 他们的隐私政策 在服务器日志里保留这些资料。我们不会去查阅或使用这些日志。

饮品建议工具

饮品建议工具完全在你的浏览器里运行。你的回答、生成的配方、分享 URL 都在你的设备上计算出来。没有任何资料送到我们的服务器，因为我们根本没有服务器，只有静态文件。

分享 URL（地址栏里 # 后面那一段）不会传给 GitHub，也不会传给我们。除非你自己复制并分享出去，否则它只留在你的设备上。

预订与 WhatsApp

预订表单会生成一条 WhatsApp 信息，并在你的设备上打开 WhatsApp。然后你自己决定是否发送。表单不会把资料传给我们的服务器；WhatsApp 信息是从你的手机经 WhatsApp 自家的基础设施送到我们的手机。

WhatsApp 信息到达我们这边后，我们会当作一般顾客咨询来处理。我们会把对话留在 WhatsApp Business 账户里，方便认出回头客，也方便事后核对预订。我们不会把信息分享给酒吧员工以外的人。我们不会出售或转交电话号码。

如果你希望我们删除 WhatsApp 对话记录，发信息告诉我们就好。WhatsApp 本身也允许你随时从自己一端删除信息。

外部请求

部分页面会从外部服务加载资源：

  • Google Fonts 提供本站使用的 DM Serif Display 与 JetBrains Mono 字体。Google 可能依据自家隐私政策记录请求。
  • Google Maps 嵌入位于酒吧页面，用于显示位置预览。这些嵌入由 Google 加载，遵循 Google 的隐私政策。

如果你不希望发出这些外部请求，可以用 uBlock Origin 或 NoScript 之类的浏览器扩充程序拦截，不会影响网站其他部分（字体会退回到系统衬线/等宽字体，地图会变成一个「在 Google Maps 中打开」的链接）。

儿童

本网站面向马来西亚法定饮酒年龄（18 岁以上）的访客。我们不会刻意收集任何儿童的资料。晚上 8 点之前，儿童可在家长陪同下进入酒吧（详见 常见问题）。

政策变更

如果有任何实质改动，我们会更新本页并刷新顶部的日期。我们不会发通知，因为我们根本没有你的电邮。

有疑问

WhatsApp 联络 Dissolved Solids 或 Soluble Solids。营业时段内一小时内回覆。
