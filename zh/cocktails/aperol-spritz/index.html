艾普罗 气泡。

艾普罗、普罗赛克、苏打水。意大利最常被点到的点酒。3-2-1 真正管用的比例。

艾普罗气泡 (Aperol Spritz) 是当下全世界点单量最高的鸡尾酒。橘红色，微苦，低酒精，为午后那段时间而生。配方简单到极致，唯一要把控的就是比例。

食材

  • 艾普罗 60ml
  • 冰镇普罗赛克 90ml
  • 苏打水 30ml
  • 半片橙片装饰
  • 大冰块（不要碎冰）

做法

  1. 在大酒杯中装满冰块。
  2. 依次倒入艾普罗、普罗赛克、苏打水。
  3. 轻轻搅拌一次。不要过度搅拌，否则气泡就没了。
  4. 用半片橙片装饰。

3-2-1 的比例

艾普罗官方比例是 3 份普罗赛克 : 2 份艾普罗 : 1 份苏打。换算成毫升大约是 90ml : 60ml : 30ml。

大多数自制版本艾普罗放得太多，整杯变得糖浆感很重。3-2-1 让它保持平衡。

选什么普罗赛克

干型（brut 或 extra dry）普罗赛克最合适。艾普罗本身就甜，如果普罗赛克也甜，整杯就会变得甜腻没层次。

推荐：任何意大利进口的 brut 普罗赛克。La Marca、Mionetto、Riondo 都行。避免最便宜的非意大利「气泡酒」，风味轮廓不同，鸡尾酒会因此受影响。

变化

金巴利气泡 (Campari Spritz)：把艾普罗换成金巴利。苦感更强烈。是意大利人觉得艾普罗气泡太「游客」时真正会点的一杯。

西娜尔气泡 (Cynar Spritz)：把艾普罗换成西娜尔（朝鲜蓟阿玛罗）。带蔬青苦感。

雨果气泡 (Hugo Spritz)：把艾普罗换成接骨木花利口酒（St-Germain）。花香、轻盈。可参考配方建构器的 hugo_spritz 模板。

Select 气泡（威尼斯版）：把艾普罗换成 Select 点酒。更多草本，更苦。

常见问题

艾普罗气泡 (Aperol Spritz) 用什么杯子？

大酒杯，加大冰块。宽口杯让气泡呼吸，橙片可以稳坐杯沿。气球杯也可以。柯林斯高直杯太窄，气泡被困住，喝第一口之后整杯就显得平了。

可以用别的酒代替艾普罗吗？

可以，但有讲究。金巴利换上后会更苦，是意大利人真正常喝的气泡。Select 点酒（威尼斯原版）更草本。西娜尔 (Cynar) 带蔬青苦感。接骨木花利口酒 (St-Germain) 则变成雨果气泡 (Hugo Spritz)。各是不同的酒，但 3-2-1 比例都通用。

艾普罗气泡有多烈？

轻盈。整杯大约 8 到 11 度，视普罗赛克而定。艾普罗本身只有 11 度，普罗赛克 11 到 12 度，再被苏打稀释。是常见鸡尾酒里酒精度数最低的一类，这正是它适合餐前点酒时段的原因。

在八打灵再也或吉隆坡哪里可以喝到艾普罗气泡？

Dissolved Solids（Damansara Kim，43-1 Jalan SS20/11，周二至周日 15:00 至 01:00，WhatsApp +60 11-4008 7607）或 Soluble Solids（SS2，50-1 Jalan SS2/24，周三至周日 18:00 至 01:00，WhatsApp +60 11-1682 8651）。两边都用干型 brut 普罗赛克，按 3-2-1 比例调。Dissolved Solids 开得早，更适合点酒时段。

艾普罗气泡配什么吃的？

意大利点酒类小食：橄榄、咸脆片、风干火腿、taralli、佛卡夏。盐焗杏仁或熟成帕玛森干酪也行。微苦的橙清理口腔，正是点酒的意义。避免甜点和重口咖喱，整杯太轻撑不住。

点酒时段。

多数夜晚都在酒单上。干型普罗赛克，新鲜橙片，比例做对。
