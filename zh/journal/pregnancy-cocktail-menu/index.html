怀孕 鸡尾酒 菜单。

给鸡尾酒吧里怀孕客人的实用 mocktail 指南。哪些行得通、要避开什么，以及为什么关于怀孕期饮品的对话值得更细致。

5 分钟阅读·来自 Dissolved Solids 的笔记

在一家鸡尾酒吧里，怀孕的客人不应该被打发去喝「冰水或一杯果汁」。任何认真的吧，无酒精那侧应该用同样的认真去对待她们。这是一份实用指南，写给怀孕客人，也写给招待她们的调酒师：哪些行得通、要避开什么、为什么这些小细节重要。

先把免责声明放在前面

我们不是医生。本指南反映的是调酒师实际经验与一般营养共识，不是医疗建议。如果你怀孕了，你产科医生的具体建议高于这里写的一切。下面的笔记基于「标准怀孕」对咖啡因与食品安全的一般指引；个体差异因人而异。

怀孕客人通常想从鸡尾酒吧得到什么

我们的经验是三件事：

1. 被纳入感。在吧里的社交体验和那杯酒一样重要。一位被塞进塑料杯子里一杯橙汁的怀孕客人，即便她自己点的橙汁，也会感觉被排斥。同样一杯饮料装在浅碟杯里、加上装饰，感觉完全不同。

2. 有意思的饮品。怀孕是「到处都只剩有限选项」的 9 个月。一家鸡尾酒吧能给出一杯真正有意思的无酒精饮品，是一件小小的体贴。

3. 不张扬。很多怀孕客人不希望整桌都注意到她没在喝酒。和别人手里同样的杯具配同样的 mocktail，能让怀孕这件事在她想要私下保留时保留。

点什么、避开什么

标准考量：

避开：

  • 任何含酒精的饮料，显而易见。包括「脱醇」葡萄酒或啤酒，它们可能仍含微量（0.5% ABV 以下），请向调酒师确认。
  • 任何含生蛋清的饮品（未巴氏处理的蛋有风险）。所有酸味形态饮品用鹰嘴豆水替代。
  • 未巴氏处理的乳制品。多数吧用的是巴氏奶与奶油；不确定就问。
  • 高咖啡因饮品。标准医学建议每天 200mg 咖啡因以下。一杯浓缩马天尼 (Espresso Martini) 风格的咖啡 mocktail 没问题；多杯咖啡饮品就累积起来了。条件允许用低咖啡因。
  • 大量喝木槿茶（部分研究建议怀孕期高剂量小心）。鸡尾酒里少量一般认为没问题，需要警惕的是大量纯茶饮用。

安全 / 推荐：

  • 新鲜果汁（柑橘、水果泥）
  • 冷萃茶（除木槿外、无咖啡因品种）
  • 通宁、苏打、气泡水
  • 椰水
  • 多数糖浆（糖、蜂蜜、椰糖）
  • 鹰嘴豆水替代蛋清

五款适合怀孕客人的 mocktail

1. 柑橘迷迭香气泡。新鲜西柚 + 柠檬 + 迷迭香糖浆 + 苏打。红酒杯。视觉上和开胃 spritz 一模一样。

2. 椰子青柠清饮。椰水 + 新鲜青柠 + 一点椰糖糖浆 + 苏打。轻盈、热带、补水。

3. 低咖啡因浓缩咖啡 mocktail。低咖啡因浓缩 + 燕麦奶奶油 + 巧克力苦精 + 一点香草糖浆。先干摇再加冰摇。浓缩马天尼的体验，无咖啡因、无酒精。

4. 洋甘菊蜂蜜酸。洋甘菊蜂蜜糖浆 + 新鲜柠檬 + 鹰嘴豆水（替代蛋清）。先干摇再加冰摇。丝滑泡沫、柔和花香、好入口。

5. 小金桔班兰高球。新鲜小金桔 + 班兰糖浆 + 苏打。本地 mocktail。明亮、易喝、有层次。

调酒师的工作

如果你是招待怀孕客人的调酒师：先问她有没有具体饮食限制，主动给 2 至 3 个 mocktail 选项，用与含酒精鸡尾酒相同的杯具与装饰，并且（最重要的）用同样的认真做单。

如果你是怀孕客人：告诉调酒师「来一杯像正经鸡尾酒一样调的、无酒精、不要生蛋」，好的调酒师会接上去。
