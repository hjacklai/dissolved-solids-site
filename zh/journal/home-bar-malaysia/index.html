马来西亚的家庭酒柜。

十瓶酒能覆盖什么、在你确定之前该跳过什么、在巴生谷到底去哪里买，以及如何不让这件事失控蔓延。

8 分钟阅读·来自 Dissolved Solids 的笔记

在马来西亚搭建家庭酒柜既好玩，又意外地省钱，前提是头十瓶买对。买错你会塞一架"做一杯就摆着"的瓶子。买对，城里多数酒单上的鸡尾酒你都能做。下面是我们会怎么想这件事。

为什么在这里值得搭一个家庭酒柜

朋友们入坑后告诉我们的三个理由：

  • 成本。一杯认真的鸡尾酒在酒吧 RM 40 到 70。同一杯在家成本可能 RM 8 到 15，基础瓶买齐之后。
  • 练习。调酒回报重复。在家倒二十杯比在酒吧点二十杯更快学会摇与搅拌。
  • 待客。你能给朋友倒一杯像样的内格罗尼 (Negroni) 或古典鸡尾酒 (Old Fashioned) 时，做主人的感觉是另一回事。

十瓶入门架

2026 年在 PJ 或 KL、预算中等地重新开始，我们会搭的架。品牌建议是家里实际在用的，没有任何赞助。

  1. 伦敦干型金酒。Tanqueray 或 Beefeater。入门架上别买太贵的小众款；你要一支干净的干型金酒，到处都用。
  2. 波本威士忌。Buffalo Trace、Maker's Mark 或 Wild Turkey 101。三选一。对新手来说波本比黑麦更宽容。
  3. 白朗姆。Bacardí 或 Plantation 3 Stars。黛吉利、莫吉托与多数热带酒款的底。
  4. 白龙舌兰 (Tequila blanco)。Olmeca Altos Plata 或 Cazadores。标签上写"100% agave"的都行。避免 mixto 那类。
  5. 伏特加。一个无聊品牌。伏特加本来就该中性。Smirnoff 或 Absolut 可以。买更贵的几乎不改变什么。
  6. 甜（红）苦艾酒。能找到 Carpano Antica 最好；否则 Cinzano Rosso。开瓶后冷藏。
  7. 干苦艾酒。Dolin Dry 或 Noilly Prat。也要冷藏。
  8. Campari。一瓶。除非你彻底爱上内格罗尼，否则在家能放很久。
  9. 柑橘三重 / Cointreau。我们会买 Cointreau；几乎不会过期。
  10. Angostura 苦精。小瓶一支。两年用不完。

这十瓶能给你做：古典鸡尾酒 (Old Fashioned)、曼哈顿 (Manhattan)、内格罗尼 (Negroni)、林荫大道 (Boulevardier)、马天尼 (Martini)（金酒或伏特加）、玛格丽特 (Margarita)、黛吉利 (Daiquiri)、威士忌酸 (Whiskey Sour)、伏特加苏打、莫吉托 (Mojito)、大都会 (Cosmopolitan)、Tom Collins，以及每一杯至少十几种变体。多数鸡尾酒单都从这一组里取材，再加一两瓶其他。

之后再添什么

把入门架喝了几个月、知道自己真喜欢什么之后，再添：

  • Aperol。如果你常点气泡饮。
  • 樱桃利口酒。Luxardo。解锁最后一句 (Last Word)、飞行 (Aviation)、海明威黛吉利 (Hemingway Daiquiri)。
  • 咖啡利口酒。Mr Black 或 Tia Maria。给浓缩马天尼 (Espresso Martini) 用。
  • 性格不同的第二支金酒。Plymouth、Hendrick's，或者支持本地的话来一支马来西亚金酒。
  • 梅斯卡尔。Del Maguero Vida 或 Mezcal Amarás。一整个世界打开。
  • 黑麦威士忌。Rittenhouse、Bulleit Rye 或 Sazerac Rye。做曼哈顿 (Manhattan) 与萨泽拉克 (Sazerac) 比波本好。
  • Lillet Blanc。给 Vesper、唤尸鬼二号 (Corpse Reviver No. 2) 用。
  • Peychaud's 苦精。给萨泽拉克 (Sazerac) 用。
  • 橙味苦精。让马天尼 (Martini) 与内格罗尼 (Negroni) 更好。

巴生谷到底去哪里买

三种主要选项，按我们用下来的可靠程度排序：

  • Cold Storage 与 Jaya Grocer（高端超市）。Jaya Grocer 较大的分店有多数标准品牌烈酒，通常是含税价。两家在 PJ 与 KL 都遍布门店。入门架的选品够用。
  • Albert Wine & Spirits、Tomei、The Single Cask。专门酒商。选品更广、店员更懂，常见品在他们那里稍贵，高端与小众瓶上反而便宜。想升级特定瓶时值得去一趟。
  • 进口商网店直购。本地一些经销商（Luen Heng、Single & Available 等）网站直营，巴生谷送货。难找到的瓶很有用。

兰卡威免税：你刚好去兰卡威的话，高端烈酒的免税购物意义不小。选品不如你期望的丰富，但品牌酒的价格常常是半岛主岸的一半。值得绕一段。

真正需要的工具

不需要三十件起步套件。你需要五样：

  • 波士顿摇酒壶（两件式，大的那半是钢罐，小的是钢杯或厚玻璃杯）。避开三件式"cobbler"摇酒壶；卡壳又咣当。
  • 吧匙。长柄、扭转柄。用来搅拌。
  • 量酒器 jigger。双头，30 毫升 / 60 毫升，或 25 毫升 / 50 毫升。"一杯酒"与"一杯平衡的酒"差就差在量。
  • Hawthorne 滤器。嵌进摇酒壶口，滤掉冰与渣。
  • 细网滤器。双重过滤（柑橘饮、蛋清饮）时放在 Hawthorne 下面。最便宜的茶滤就行。

整套不到 RM 200。捣压棒、柑橘榨汁器、鸡尾酒签、速倒嘴，等你确定某杯酒需要它们再买。我们见过太多家庭酒柜配件齐全、酒却倒不出几杯的。

冰的问题

你家冰箱的冰多半是家中酒柜里最弱的一环。比酒吧冰小，化得快，把酒稀释过头。两种修法：

  • 买大颗硅胶冰格。一颗 5 厘米的方块比十颗小冰化得慢得多。古典鸡尾酒 (Old Fashioned)、内格罗尼 (Negroni)、任何加冰款都用一颗大冰。
  • 摇制饮品里用的冰不是上桌的冰。摇用什么冰都行；双重过滤入冰镇过的无冰杯（浅碟、马天尼杯）。

在你确定之前先跳过什么

大家常买、结果多半摆架上的：

  • 紫罗兰、薄荷、黑莓利口酒等小品种 crème。仅适用于少数酒款。等你有明确用途再买。
  • 白兰地 / 干邑。很好，但马来西亚的干邑稍有品质就贵。除非你确定喜欢白兰地系酒款，否则先跳过。
  • 高端单一麦芽苏格兰。那种酒纯饮，不进鸡尾酒。用一支 25 年苏格兰做调酒近乎犯罪。
  • 多种形状的杯具。浅碟杯 + 古典杯 + 高球杯就覆盖一切。换更"对"的杯子并不让酒变更好；只让你多洗几只。

一点小哲学

多数家庭酒柜需要的最大单一改进，不是再添一瓶。是测量。jigger 是家庭调酒里最被忽视的工具。一杯用便宜金酒按比例做对的酒，胜过一杯用高端金酒乱倒出来的。前六个月一切都测量。之后你会开始感觉到比例；之前你会一直做出略偏的酒，又搞不清为什么。

想校准"什么是对的比例"，开做之前去几家不同的酒吧喝同一杯酒。校准很有帮助。

常见问题

在马来西亚起家庭酒柜需要哪十瓶？

London Dry 金酒（Tanqueray 或 Beefeater）、波本（Buffalo Trace、Maker's Mark 或 Wild Turkey 101）、白朗姆（Bacardi 或 Plantation 3 Stars）、龙舌兰 blanco（100% agave）、伏特加（任何中性品牌）、甜苦艾酒（Carpano Antica 或 Cinzano Rosso）、干苦艾酒（Dolin Dry 或 Noilly Prat）、金巴利、Cointreau、Angostura 苦精。覆盖古典、曼哈顿、内格罗尼、马天尼、玛格丽特、黛吉利和几十款其他。

巴生谷哪里买家庭酒柜的烈酒？

三个可靠选项。Cold Storage 与 Jaya Grocer（高档超市）按完税价备多数大牌烈酒。专门店 Albert Wine & Spirits、Tomei、The Single Cask 选择更广、员工更懂。直接从进口商网店（Luen Heng、Single & Available）买难找的瓶，巴生谷送货。兰卡威免税值得绕一程拿高端品牌。

家庭酒柜需要哪些工具？

五样，整套 RM 200 以内。Boston 摇壶（两件，钢罐加品脱杯；避免 cobbler）。吧勺搅拌。量酒杯（30/60ml 或 25/50ml；量是把酒与平衡的酒分开的东西）。Hawthorne 滤网给摇壶。细网做柑橘与蛋清的双重过滤。捣压杵、榨汁器、瓶嘴等到有具体酒款需要再加。

超市冰可以代替家用合格吧台冰吗？

家用冰箱冰是多数家用设置最弱的部分；它比吧台冰小、融化快、稀释酒。两个补救。买大 5cm 硅胶冰球模；一颗大冰慢融够撑古典。摇制酒款里，摇的冰不是端给客人的冰：用任何冰摇，再双重滤入冰镇浅碟不加冰。
