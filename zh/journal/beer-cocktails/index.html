啤酒 入鸡尾酒。

啤酒是地球上消费量最大的发酵饮品，却是鸡尾酒吧用得最少的之一。五种可行的格式，外加一杯值得认识的马来西亚啤酒鸡尾酒。

5 分钟阅读·来自 Dissolved Solids 的笔记

啤酒与鸡尾酒通常被分开放：啤酒喝家喝啤酒，鸡尾酒喝家喝鸡尾酒，酒单分两栏列。这更多是传统而非化学。啤酒可以和冰箱里任何东西一样，成为一杯酒的结构成分。前提是你要像对待基酒那样认真考虑啤酒类型。

五种啤酒鸡尾酒格式

1. Boilermaker。一 shot 威士忌 + 一杯啤酒，一起喝。整杯丢进啤酒里（shot 杯沉进啤酒），或者按顺序（先 shot 再啤酒）。最简单的啤酒鸡尾酒。用波本配干净拉格，或爱尔兰威士忌配干型黑啤最好。

2. Michelada。墨西哥格式。拉格 + 青柠 + 伍斯特酱 + 辣酱 + 盐边。喝起来像啤酒版血腥玛丽。配墨西哥菜很好，尤其是 tacos。

3. Shandy / Radler。拉格 + 柠檬水或西柚苏打，50:50。低 ABV、解渴，热带气候量身打造。马来西亚冰柠檬茶 shandy 的变体很好喝：拉格 + 冰柠檬茶，50:50。

4. Beertails（现代格式）。啤酒 + 烈酒 + 柑橘 + 甜味，摇制或现调。IPA Sour、Stout Old Fashioned、Lager Margarita。把啤酒当结构性辅料。

5. Black Velvet。世涛 + 香槟，分层。视觉戏剧感，喝起来像一杯奶感苦甜的气泡酒。

啤酒类型与鸡尾酒格式的搭配

拉格（Tiger、Carlsberg、Anchor）：最灵活的啤酒鸡尾酒基底。用在 Boilermaker、Michelada、Shandy。拉格 + 龙舌兰 + 青柠 + 西柚苏打做出来的长饮很棒。

IPA：啤酒花特征与柑橘天生相合。用在 IPA Sour（IPA + 金酒 + 柠檬 + 单糖浆），或当作气泡饮的顶层替代苏打。

世涛 / 波特：巧克力与咖啡的轮廓与波本、深色朗姆、陈年烈酒搭配。Stout Old Fashioned（世涛 + 波本 + 枫糖 + 巧克力苦精）是经典做法。

小麦啤酒（Hoegaarden、Weihenstephan）：果香与香料的轮廓与柑橘和花香相配。小麦啤酒 + 金酒 + 接骨木 + 柠檬，夏天的形状。

酸啤 / 野生啤（Lambic、Gose）：因天然酸度本身就在鸡尾酒地界。在低 ABV 鸡尾酒里充当柑橘成分。

三杯值得倒的酒

1. Michelada。拉格 180ml、鲜青柠汁 20ml、伍斯特酱 4 dash、Tabasco 4 dash、一大撮盐 + Tajín 风格的辣盐做杯口。在盐口品脱杯里加冰现调。装饰：青柠片。

2. Stout Old Fashioned。波本 40ml、demerara 糖浆 5ml、巧克力苦精 2 dash，上面加约 60ml 干型世涛。一大颗冰块上现调。浓郁，餐后形状。

3. Tiger Shandy 加小金桔。Tiger 啤酒 180ml、鲜小金桔汁 30ml、椰糖糖浆 10ml。冰上现调。马来西亚冰柠檬茶 shandy 的逻辑换成小金桔。本地热天的啤酒鸡尾酒。

不要做什么

啤酒 + 重奶油。气泡把奶油结块。跳过。

啤酒 + 极高度烈酒同量。啤酒消失了；你只是稀释了烈酒。啤酒以较大量（60 至 180ml）配较小量烈酒（30 至 45ml）。

把甜味的调味手工啤酒拿来调酒。外加的风味会打乱平衡。鸡尾酒用，请守住传统类型。

本地脉络

马来西亚有一支小而真的手工啤酒圈（Tiger Crystal、Tropical Hop，以及更小的微型酿造商）。马来西亚鸡尾酒里，Tiger Lager 与 Tiger Crystal 是主力；更野心的做法可以去较好的酒商那里找比利时与德国特色啤酒。
